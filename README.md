# Puppy Care in San Antonio (`puppy-vet-guide-sa`)

A lightweight, mobile-first single-page reference website designed for San Antonio puppy owners to easily navigate their new puppy's veterinary schedule without confusion or unnecessary phone calls. It lays out the critical first-year vaccination and prevention timeline, provides side-by-side breakdowns for the best low-cost appointment clinic (San Antonio Humane Society) and walk-in pop-up clinic (Low Cost Pet Vax), walks through the exact online appointment booking steps with screenshots and an animated GIF walkthrough, explains mandatory proof-of-residency rules for the 100% free City of San Antonio spay/neuter grant, and clarifies how pet insurance interacts with routine preventive care.

## Deploying to GitHub Pages

1. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/<username>/puppy-vet-guide-sa.git
   git branch -M main
   git push -u origin main
   ```
2. On GitHub, navigate to **Settings** > **Pages**.
3. Under **Build and deployment**, select **Source: Deploy from a branch**.
4. Set branch to `main` and directory to `/ (root)`, then click **Save**.
5. The live site will publish to `https://<username>.github.io/puppy-vet-guide-sa/`.
